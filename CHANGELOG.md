# Changelog

## 1.0.0

- Initial public release.
- Exact URL routing to any number of browsers and profiles.
- Automatic Chrome, Brave, Edge, and Firefox discovery.
- Microsoft Teams and Outlook Safe Links destination matching.
- Native AOT build for fast startup and a small standalone executable.
- GUI-subsystem executable with no command-window flash.
- Per-user Windows installer and Default Apps registration.
